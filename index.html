IEEE CONIT 2026 · Patent 202621042187

Solar-powered AIoT system for precision agriculture in monsoon-dependent farming regions. SVR-based rainfall prediction, ResNet50 crop identification, and a rule-based irrigation controller that only triggers when soil moisture, rainfall forecast, and crop health all agree.

Build notes
  • SVR outperformed LightGBM and GRU on the Konkan coastal dataset — chosen for highest precision, not just accuracy.
  • ResNet50 hit 99.7% test accuracy; EfficientNetB0 overfit catastrophically (16% test vs 99.7% val) and was discarded.
  • Three-gate irrigation logic: pump only triggers when soil moisture is low, rainfall probability below 60%, no active disease.
  • ESP32 + BME280 syncs to Firebase every 5 seconds, running off solar and Li-ion battery.
  • React Native app with live sensor dashboard, manual override, and Kindwise API disease diagnosis from leaf photos.
