SoilStream

aiot · precision agriculture · solar-powered

Solar-powered AIoT system for precision agriculture in monsoon-dependent farming regions. SVR-based rainfall prediction, ResNet50 crop identification, and a conservative rule-based irrigation controller that only runs the pump when all three conditions — soil moisture, rainfall forecast, and crop health — agree.

92.86% rainfall accuracy
99.7% crop identification
0.93 svr precision
python tensorflow svr resnet50 esp32 firebase react native flask lightgbm
github →
  • SVR rainfall model outperformed LightGBM and GRU on Konkan coastal dataset — chosen for highest precision, not just accuracy
  • ResNet50 multi-class crop classifier at 99.7% test accuracy; EfficientNetB0 overfit catastrophically at 16% test accuracy despite 99.7% val — correctly diagnosed and discarded
  • Irrigation controller only activates when soil moisture is low, rainfall probability is below 60%, and no active disease is detected — three-gate logic
  • ESP32 + BME280 pipeline syncing to Firebase Realtime Database every 5 seconds, running entirely off solar and Li-ion battery
  • React Native app with live sensor dashboard, manual pump override, and Kindwise API-powered disease diagnosis from leaf photos
